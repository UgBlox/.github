# UgBlox .github

Organization profile, shared workflows and issue/PR templates.

## Layout

```
profile/README.md        public org profile
ISSUE_TEMPLATE/          default issue forms for repos without their own
PULL_REQUEST_TEMPLATE.md default PR template
workflow-templates/      reusable CI starters for new repos
```

## Rules

- This repo MUST stay public, or GitHub ignores the defaults it provides.
- It MUST NOT contain code, secrets or internal plans.
- Members-only profile content MUST go in a separate `.github-private` repo at `profile/README.md`.
